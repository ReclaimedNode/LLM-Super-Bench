# Long-context test: notice

These questions are written by this project (`src/quality/longctx.ts`) from a fixed seed, so nothing is downloaded and every
machine gets the same text. They are modelled on:

- **RULER**, NVIDIA, *RULER: What's the Real Context Size of Your Long-Context Language Models?*, 2024,
  <https://arxiv.org/abs/2404.06654>, <https://github.com/NVIDIA/RULER> (Apache License 2.0): the multi-key and
  variable-tracking tasks.
- **Needle in a haystack**, Greg Kamradt, <https://github.com/gkamradt/LLMTest_NeedleInAHaystack> (MIT, which asks for
  attribution): burying one fact at a chosen depth in plain text.

No code or text from either project is copied. These are not the published RULER questions, so a score here is for comparing
your machines with each other, not with RULER's numbers.
